# Kế hoạch

## Đang làm
- Chặng 1: khung web công thức nấu ăn (PR đầu tiên).

## Tiếp theo
- Chủ dự án bật GitHub Pages (Settings → Pages → Source: GitHub Actions), merge PR.
- Tạo Google Sheet theo `data/README.md`, thêm secret `SHEET_ID`.
- Chọn tên web và tên repo chính thức.
- Chặng 2: 30–50 món đầu tiên có video.

## Quyết định đã chốt
- Đổi chủ đề từ "kiến thức làm mẹ" sang công thức nấu ăn đủ loại món (16/11/2026).
- Giữ kiến trúc: web tĩnh + Google Sheets, dùng được như app.
